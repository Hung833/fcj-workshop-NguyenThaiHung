Typically, and as a standard practice, a worklog is maintained throughout the entire internship period, with weekly content organized as follows. The internship program ran for **9 weeks**, from 01/06/2026 to 30/07/2026, during which I was responsible for the **AI/Data - MLOps & Pipeline** track (while my teammate handled Frontend/API) for the **"AI Pulmonary Diagnostic Suite"** project — a pneumonia diagnostic system based on chest X-ray images, built and deployed following a standard MLOps workflow on AWS:

**Week 1:** [Program orientation, setting up the working environment, and getting familiar with core AWS services (EC2, S3, VPC, IAM)](1.1-week1/)

**Week 2:** [Building the Toy Dataset and completing Tech Blog #1 on Serverless MLOps architecture](1.2-week2/)

**Week 3:** [Automating the data preprocessing step on an Amazon SageMaker Processing Job](1.3-week3/)

**Week 4:** [Training the DenseNet121 model using a SageMaker Training Job](1.4-week4/)

**Week 5:** [Optimizing model parameters via Hyperparameter Tuning (HPO) and completing Tech Blog #2](1.5-week5/)

**Week 6:** [Managing model versions through SageMaker Model Registry and preparing the Custom Inference Handler](1.6-week6/)

**Week 7:** [Deploying the model to a Serverless Endpoint, connecting Lambda and API Gateway](1.7-week7/)

**Week 8:** [Setting up automated error monitoring (CloudWatch, SNS), building a complete MLOps Pipeline, and completing Tech Blog #3](1.8-week8/)

**Week 9:** [Finalizing the Web interface (Streamlit), running end-to-end testing, wrapping up the FinOps cost report, and closing out the project](1.9-week9/)
